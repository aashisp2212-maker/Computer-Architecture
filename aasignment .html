SkyField Autonomous Drone Processor

Interactive Computer Architecture Design & Simulation Web Application

Problem Statement

SkyField Robotics needs a real-time onboard processor for a mid-range autonomous drone used for crop monitoring and disaster surveying. The processor must fuse IMU, GPS and barometric data, execute control-loop calculations, log telemetry and respond rapidly to emergency conditions.

Sensor Data→ISA / Datapath→Arithmetic→Control→Telemetry

Architecture Modules

10 instructions Custom ISA with immediate, register-indirect and indexed addressing.

Fast arithmetic Carry-Look-Ahead Adder and Non-Restoring Division.

Memory & Control

2-way issue Simple superscalar/out-of-order dispatch.

2-level paging TLB hit/miss translation and process isolation.

Priority ISR Vectored emergency interrupts.
